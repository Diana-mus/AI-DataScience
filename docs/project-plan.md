# AI Lab – 8-Puzzle Solver

## Project Goal
Implement the A* Search algorithm to solve the
8-Puzzle using two heuristics:
- Hamming Distance
- Manhattan Distance

Compare their performance using 100 random
solvable starting states.

## Team Responsibilities

### Person 1 – Puzzle Logic
- Represent the puzzle
- Generate valid moves
- Check solvability
- Generate random solvable puzzles

### Person 2 – A* Algorithm
- Implement A* Search
- Manage open and closed lists
- Calculate search costs
- Reconstruct the solution path

### Person 3 – Heuristics
- Implement Hamming Distance
- Implement Manhattan Distance
- Test heuristic functions

### Person 4 – Experiments
- Run 100 searches per heuristic
- Measure runtime
- Measure node counts
- Calculate mean and variance
- Compare results

## Shared Responsibilities
- Software architecture
- Integration testing
- Documentation
- Group presentation
